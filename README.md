# 페달 체크 (PedalCheck)

> **오늘의 내 발을 30초 만에.** 주차한 차에서 화면 신호에 맞춰 브레이크 페달을 밟아 반응속도를 재고, 절대 속도가 아니라 **평소의 나와 비교**해 운전 컨디션을 알려 주는 자가 점검 앱입니다.

- 대상 환경: Pleos Connect 에뮬레이터 (Android / Kotlin / Pleos Connect SDK)
- 제출 APK: [`apk/정통윤_PedalCheck_release.apk`](apk/%EC%A0%95%ED%86%B5%EC%9C%A4_PedalCheck_release.apk) (release 서명). 소스에서 직접 만들려면 [소스에서 빌드](docs/소스에서_빌드.md)
- 이 앱은 차량에 아무것도 쓰지 않는 **읽기 전용** 앱입니다.

## 무엇을 하나

| 기능 | 동작 | 상태 |
|---|---|---|
| 실행 조건 확인 | 기어 P, 정차(속도 0.3m/s 이하, 주행 규제 없음)일 때만 시작할 수 있음. 측정 중 조건이 깨지면 즉시 중단하고 기록하지 않음 | 구현 |
| 30초 측정 | 회색 원이 무작위(1.5~4초)로 빨갛게 바뀌면 브레이크를 밟음. 빨강 5회 + 초록 1회(초록은 밟지 않고 참기). 먼저 밟으면 부정 출발로 같은 회차를 다시 함. 제대로 밟으면 초록 테두리와 확인음, 틀리게 밟으면 빨간 테두리와 약한 화면 흔들림. 한 번 켜졌다 꺼지며 깜빡임 없고, 다음 회차가 시작되면 기본 상태로 돌아옴. 빨강 신호 자체에는 소리 없음 | 구현 |
| 평균 | 정상 빨강 5개에서 가장 빠른 값과 가장 느린 값을 빼고 3개를 평균 | 구현 |
| 개인 기준선 | 처음 완료한 세션부터 14일 동안의 세션 평균 중앙값(5개 이상). 그 전에는 "기준선 만드는 중 n/5"로 오늘 평균만 보여 줌 | 구현 |
| 오늘 결과 | "평소보다 N% 느려요 · 평소 범위예요". 15%를 넘게 느리면 늦게 멈추는 거리(시속 60km 기준)와 쉬어 가기 제안. 합격/불합격 표현 없음 | 구현 |
| 기록 저장 | 기기 안 Room DB에만 저장, 외부 전송 없음 | 구현 |
| 월별 추이 | 월별 중앙값 그래프(세션 3개 미만인 달은 점선), 날짜별 기록은 본인만 | 구현 |
| 가족 공유 미리보기 | 월별 추이 그래프만 보여 줌. 날마다의 점수·측정 시각과 장소는 보내지 않음. 동의 스위치. 실제 전송은 없는 미리보기 | 구현 |
| 3개월 안내 | 이어진 최근 3개월의 월별 값이 이번 달까지 매달 커지면 본인 화면에만 한 번 안내(같은 달 재표시 없음). `운전능력진단 안내 보기`는 "[2차 개발 범위로 현재 미구현]"만 표시 | 구현 |
| 음성 안내(TTS) | 앱을 열 때 "오늘 30초 체크할까요?"를 한 번만 말함(오늘 이미 쟀으면 말하지 않음). 같은 말풍선은 실행 조건 화면에 항상 표시. 측정 중에는 음성 없음 | 구현 |
| 출발 전 제안(내비) | 30km 이상 길안내를 시작했고 오늘 측정이 없으면 홈에 "출발 전에 30초 체크할까요?" 카드. 거리 기준은 설정에서 변경 | 구현 |
| 음성 명령(Gleo) | `PEDAL_CHECK_START`(실행 조건 화면), `MY_PEDAL_TREND`(추이 화면). 실제 Gleo 호출은 심사 후 활성화되어 adb로 같은 intent를 보내 시연 | 구현 |
| 시연 모드 패널 | 시연 모드에서 측정 화면 오른쪽에 '운전석 발밑' 그림(브레이크 리스너 값으로 움직임)과 차량 신호 체크 | 구현 |

결과 화면 아래에는 항상 "자가 점검이며 의료·면허 판단이 아닙니다"를 표시합니다.

핵심 로직(측정 엔진, 기준선·비교·거리 환산, 실행 조건 판정)은 Android에 의존하지 않는 순수 Kotlin이고 단위 테스트 77건이 있습니다. 반응시간은 신호가 그려진 프레임 시각과 브레이크 리스너 시각을 같은 시계(`System.nanoTime()`)로 재어 구합니다. 화면 표시나 차량 신호 전달의 일정한 지연은 기준선과 오늘 값에 똑같이 들어가 비교에서 상쇄되므로, 앱은 절대 반응속도를 평가하지 않고 평소 대비만 말합니다.

## 테스트 환경과 필요한 설정

- Pleos Connect 에뮬레이터 (AVD `Pleos_Connect_v2.1.0`, Cold boot, RAM 4GB, 2560×1440). 앱은 가로 화면 전용 레이아웃입니다.
- 권한은 설치 때 허용합니다: `adb install -g <APK>`. 차속 권한(`android.car.permission.CAR_SPEED`)은 `-g`로 주지 않아도 첫 실행 때 앱이 요청합니다.
- 에뮬레이터에서 브레이크를 밟는 방법은 **에뮬레이터 창에서 스페이스바**를 누르는 것입니다(Python 불필요). 앱이 스페이스바를 받아 에뮬레이터 안의 Virtual Console(`127.0.0.1:8088`)에 브레이크 100/0을 보내고, 차량 신호가 Pleos 브레이크 리스너로 돌아와 측정에 쓰입니다. Virtual Console의 Brake 값을 직접 바꿔도 됩니다.
- 주차 브레이크는 에뮬레이터에서 값을 확인할 수 없어 실행 조건에서 뺐습니다. 실행 조건 화면에는 "확인할 수 없어요"로 표시됩니다.

## 실행 방법

1. 에뮬레이터를 켜고 앱을 설치·실행합니다(`페달 체크`).
2. 홈에서 `30초 체크` → 실행 조건이 모두 ✓이면 `시작`. 원이 **빨강**이면 에뮬레이터 창에서 스페이스바를 눌렀다 떼고, **초록**이면 누르지 않습니다. 키는 미리 연결되어 있어 따로 설정할 것이 없습니다.
3. 결과 화면에서 오늘 평균과 기준선 비교를 봅니다.

Virtual Console 연결이 없으면(웹페이지가 닫혀 503 등) 스페이스바 입력을 앱이 직접 받아 측정합니다. 이때는 차량 신호가 아니므로 측정 화면 위에 "직접 입력 중 · 차량 신호가 아니에요"가 표시됩니다. 차량 신호 경로를 쓰려면 Virtual Console 웹페이지를 열어 두세요(`adb forward tcp:8088 tcp:8088` 후 `http://127.0.0.1:8088/`).

### 앱 밖에서 키를 보내고 싶을 때 (선택)

에뮬레이터 창이 아니라 PC 전역에서 스페이스바를 받고 싶다면 `tools/key_bridge.py`를 씁니다. `adb forward tcp:8088 tcp:8088` 후 `python tools/key_bridge.py`. Virtual Console 하트비트도 함께 보내므로 웹페이지를 열어 둘 필요가 없습니다. 종료(Ctrl+C)하면 브레이크를 0으로 되돌립니다. 앱의 스페이스바 입력과 동시에 쓰지 마세요(같은 키가 두 번 전해집니다).

### 시연 모드로 비교 화면 보기

처음 14일 기록이 쌓이기 전에도 비교 화면을 보려면 `설정` → `시연 모드`를 켭니다.

- `기준선으로 지정`: 기준선을 직접 정함(예: 600ms). 키보드로 직접 재 본 중앙값을 넣는 용도입니다.
- `지금 기록으로 기준선 만들기`: 기록이 5개 이상일 때 지금까지 기록의 중앙값으로 만듦
- `기준선 지우기`, `기록 모두 지우기`

시연용으로 정한 기준선은 화면에 "(시연용)"으로 표시됩니다.

### 추이·가족 미리보기·3개월 안내 시연

과거 기록이 없어도 `설정` → `시연 모드` → `시연용 기록 넣기`로 시연용 기록 21건(2달 전 10건, 1달 전 6건, 이번 달 5건)과 기준선이 들어갑니다. 홈에 3개월 안내 카드가 뜨고, `추이`에서 월별 그래프와 `가족과 나누기`를 볼 수 있습니다. 시연용 기록에는 "시연용"이 표시되고 `시연용 기록 지우기`로 지웁니다.

- 오늘 측정한 기록은 진짜 값이라 이번 달 값에 섞입니다. 깨끗이 시연하려면 먼저 `기록 모두 지우기`를 한 뒤 시연용 기록을 넣으세요.
- 시연용 기록의 기준값은 `tools/seed_history.py --baseline <ms>`로 바꿔 `app/src/main/assets/demo_history.json`을 다시 만들고 앱을 다시 빌드하면 됩니다(현재 374ms).

### 음성 명령(Gleo)·출발 전 제안·시연 패널

```
adb shell am start -a PEDAL_CHECK_START    # 실행 조건 화면 (주행 중이면 "주행 중에는 쓸 수 없어요")
adb shell am start -a MY_PEDAL_TREND       # 월별 추이 화면
```

- 두 명령은 측정 중에는 화면을 바꾸지 않습니다.
- 출발 전 제안은 앱이 내비 이벤트를 받을 때 뜹니다. 에뮬레이터에서는 내비 앱에서 목적지를 정해 길안내를 시작하세요(거리 30km 이상). 거리 기준은 `설정`의 "출발 전 제안 거리"에서 바꿉니다. 앱 자체는 길안내를 걸지 않습니다(debug 빌드에만 시험용 수신기가 있고 release에는 없음).
- 시연 패널은 `설정` → `시연 모드`를 켜면 측정 화면 오른쪽에 나타납니다. 스페이스바를 누르면 발이 내려가고 페달이 눌립니다.

### 차량 조건 바꿔 보기

기어를 바꾸면 조건이 즉시 반영됩니다. `PUT http://127.0.0.1:8088/vehicle/gear?gear=Drive` (또는 `Park`). 측정 중 D로 바꾸면 즉시 중단되고 P로 돌아오면 "측정을 멈췄어요 · 기어가 P에서 바뀌었어요 · 기록하지 않았어요"가 보입니다. 기어 D인 동안은 OS가 앱 화면을 가립니다.
