# 알려진 한계

[← README](../README.md)

- **절대 반응속도가 아닙니다.** 화면 표시 지연과 차량 신호 전달 지연이 값에 일정하게 들어 있어, 앱은 "정상 범위" 같은 절대 평가를 하지 않고 평소 대비 변화만 보여 줍니다. 에뮬레이터에서는 평균 지연의 절대값을 측정할 수 없었습니다.
- **주차 브레이크는 확인하지 못합니다.** `PARKING_BRAKE_ON` 값은 읽히지만 항상 `false`이고, Virtual Console 조작으로 바뀌지 않았습니다. 그래서 실행 조건은 "기어 P, 정차" 2개입니다.
- 기어가 D인 동안 Pleos OS가 앱 화면을 가립니다("주행 중에는 사용할 수 없습니다"). 측정 중이었다면 앱은 즉시 중단하고, P로 돌아오면 중단 화면이 보입니다.
- 좌석 위치로 사용자를 구분하는 기능은 넣지 않았습니다(좌석 위치 API를 검증하지 못함). 기준선은 사용자 1명 기준입니다.
- 측정 상수(너무 빠름 100ms, 놓침 1.5초, 4번째 중단)는 기획서에 없는 값이라 키보드로 직접 재 본 뒤 조정할 수 있게 상수로 두었습니다.
- 기준선은 처음 14일 동안 5개 이상의 세션이 있어야 만들어집니다. 14일 안에 5개가 모이지 않으면 다섯 번째 세션이 생길 때까지 기간이 늘어납니다(기획서에 없는 보완 규칙).
- 3개월 안내의 `운전능력진단 안내 보기`는 실제 안내 문구와 링크가 없어 "[2차 개발 범위로 현재 미구현]"만 보여 줍니다. 안내 조건은 기획서에 정확한 기준이 없어 "이어진 3개월의 월별 값이 이번 달까지 매달 커짐"으로 정했습니다.
- 가족 공유는 앱 안 미리보기이며 실제로 전송하지 않습니다. 가족 화면의 월별 그래프는 값 차이가 보이도록 눈금을 좁게 잡아서, 숫자를 함께 적었습니다.
- **음성(TTS)은 시작 질문 한 번만** 시도합니다. 에뮬레이터에서 재부팅 직후 첫 호출만 이벤트가 확실했고 반복 호출은 오지 않아서입니다. 실패해도 앱은 멈추지 않고 같은 말풍선이 화면에 있습니다. 실제 소리는 들어 보지 못했고 `init ok → speak → onStart` 로그만 확인했습니다.
- 출발 전 제안의 거리 기준(30km)은 기획서에 없는 값이라 설정에서 바꿀 수 있게 했습니다. 길안내 거리는 `onRouteStarted`의 값(미터)을 씁니다. 에뮬레이터에서 천안 길안내(78km)로 확인했습니다.
- Gleo는 실제 호출이 심사 후 활성화되어, 시연은 adb로 같은 intent를 보냅니다.
- 제출 영상은 앱 화면 녹화가 아니라 목업 영상입니다. 목업에는 앱에 없는 "주차 브레이크 확인" 장면이 있습니다.
- 시연 모드의 '운전석 발밑' 그림은 단순한 도형입니다. 목업의 속도선·물결 같은 연출은 넣지 않았습니다.
- 사람이 물리 키보드(스페이스바)로 직접 재는 확인은 아직 하지 못했습니다. 신호를 보고 키 이벤트를 보내 주는 방식으로만 확인했습니다.

각 항목의 측정값과 근거는 [검증 기록](검증기록.md)에 있습니다.
