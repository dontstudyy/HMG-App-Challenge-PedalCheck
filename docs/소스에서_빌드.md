# 소스에서 빌드

[← README](../README.md)

필요한 것: Android SDK(compileSdk 37)와 JDK(Android Studio에 포함된 JBR), 그리고 Pleos 라이브러리 저장소(`nexus-playground.pleos.ai`)에 접근할 인터넷.

```
# 저장소 루트의 local.properties에 sdk.dir 지정 후
gradlew.bat testDebugUnitTest assembleDebug     # 인터넷 필요(Pleos 라이브러리 저장소)
gradlew.bat assembleRelease                     # keystore.properties가 없으면 debug 키로 서명
```

설치: `adb install -g app/build/outputs/apk/debug/app-debug.apk`

서명 키스토어와 `keystore.properties`는 저장소에 없습니다(저장소 밖 보관). release는 R8 최적화를 켜고 `kotlin.**` 보존 규칙(`app/src/main/keepRules/rules.keep`)을 둡니다.

## 키스토어 설정 (제출용 서명)

저장소 루트에 `keystore.properties`(gitignore 대상)를 두면 release가 그 키로 서명됩니다. 키스토어는 저장소 밖의 별도 폴더에 두었습니다. 키 이름만 적습니다(값은 저장소에 없습니다). 만드는 법: `keytool -genkeypair -keystore <경로> -alias pedalcheck -keyalg RSA -keysize 2048 -validity 10000`

```
storeFile=<키스토어 경로>
storePassword=<...>
keyAlias=<...>
keyPassword=<...>
```

## 테스트

```
gradlew.bat testDebugUnitTest           # 앱 단위 테스트 77건(측정 엔진, 기준선·비교, 추이, 실행 조건 판정, 시연용 기록, 출발 전 제안, 판정 연출 곡선)
```

## 참고

- Windows에서 Gradle은 PowerShell에서 실행하는 것이 안전했습니다(Git Bash에서는 Kotlin 데몬·AAPT2 시작이 실패한 적이 있음).
- 처음 빌드할 때 의존성 내려받기로 몇 분 걸립니다. release 빌드는 약 5분이 걸렸습니다.
- release(R8 최적화) 빌드가 에뮬레이터에서 실행되는 것을 확인했습니다(debug 키 서명 기준, [검증 기록](검증기록.md#release r8 최적화-빌드-2026-11-15)).
